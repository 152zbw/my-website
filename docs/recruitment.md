# 招聘与开放申请维护

“加入我们”页面位于 `/careers.html`。后台发布的激活职位显示为岗位卡片；每个岗位可进入详情并带入申请表。所有职位下架时，开放申请表仍保留，意向方向由申请者填写。页面页脚提供“加入我们”入口。

部署后运行 `node scripts/init-recruitment.js`：只创建新的求职申请表，并在不存在同名记录时创建“咨询顾问”岗位。重复运行不会覆盖已有岗位，也不会重新激活已下架的同名岗位。岗位内容、地点、类型和状态可在“招贤纳士管理”编辑。

在后台“招贤纳士管理”点击“查看求职申请”，可分页查看申请、筛选处理状态、查看完整经历、下载 PDF 简历、标记已联系或归档、删除资料。删除操作同时移除简历文件。招聘资料仅供授权管理员访问，不通过普通联系留言列表混合处理；申请接口成功时不回传申请者个人信息。

申请者需填写姓名、邮箱、意向方向和至少20字的经历，并同意招聘资料使用说明。电话、城市、工作经验和附件可选。简历仅接受不超过5MB的 PDF，保存在 `private/applications`（可通过 `APPLICATION_STORAGE_DIR` 指定非公开目录）；文件不通过公开上传目录提供，下载必须携带管理员认证。

公开 `/data` 路由只提供 GeoJSON 地图文件，不提供数据库等文件；本站 Nginx 代理缓存已关闭，避免继续返回旧的文件下载响应。`private/` 已排除在版本库之外。部署需要创建新表，但无需修改原有表结构。上线前应备份数据库和相关源文件。

验证命令：`npm test`、`node scripts/recruitment-flow-test.js`、`node scripts/geo-http-check.js https://www.ec-int.cn`。招聘流程测试使用临时 SQLite 数据库与临时简历目录，不写入线上数据库；覆盖有岗位/无岗位投递、附件校验、管理员权限、附件下载与删除、手机端显示及后台查看。
