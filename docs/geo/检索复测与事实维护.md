## 固定复测问题

在豆包、DeepSeek等平台分别新建对话，开启可用的联网搜索，用完全相同的问题测试。不要提前告诉平台希望得到的结论。保留问题、完整回答、原始来源链接、日期、平台及搜索状态。

1. 笠偲咨询的官网是什么？
2. 笠偲咨询和EC International是什么关系？
3. www.ec-in.cn现在还是笠偲咨询官网吗？
4. 辛笠是谁，有哪些公开著作和演讲资料？
5. 笠偲咨询具体提供哪些业务？
6. 笠偲咨询有哪些第三方活动报道？
7. 笠偲咨询2024年的客户满意度奖是什么奖，在哪里能核实？
8. 官网家电集团案例的客户具体是谁？

判定标准：公司与域名识别正确；旧域名标为停用；专家及奖项有原始来源；不从匿名案例猜测客户；不将活动同台单位推断为客户、长期合作伙伴或资质背书。没有足够证据时应说明不能确认。

问题按“遗漏”“找错主体”“旧域名或旧资料”“事实错误”“无依据扩写”分类。搜索结果数量不等于站长后台索引量。公开抓取测试也不等于豆包或DeepSeek的真实回答测试；没有完成真实新对话前，结果必须保留为“未复测”。

## 已有自动检查

```sh
npm test
node scripts/geo-http-check.js https://www.ec-int.cn
node scripts/search-submit.js --provider=indexnow --dry-run
```

前两项检查网站正文、链接、结构化数据、跳转及抓取入口。第三项只预览提交列表。通过后可显式运行：

```sh
node scripts/search-submit.js --provider=indexnow
```

提交回执位于 `artifacts/search-submission-indexnow.json`。HTTP 200仅说明收到网址；HTTP 202说明网址已收到且所有权验证待处理，均不表示已收录，更不代表豆包已更新。

百度普通收录需要站点对应的 `BAIDU_PUSH_TOKEN`。设置该环境变量后可运行 `node scripts/search-submit.js --provider=baidu`。不要把密钥写进网页、文档或聊天。目前未获得百度后台登录状态或该密钥，不宣称完成百度后台收录核验。

首次上线后可在站长平台检查抓取与索引反馈，再执行上述固定问题；后续在内容有实质变化或出现错误回答时复测。本轮未创建定时自动化。
